# Personal budget

Terms for categorizing transactions and filtering report results.

## Language

**Included tag**:
A tag a transaction must have at least one of when included-tag filters are selected.
_Avoid_: Required tag

**Excluded tag**:
A tag that removes a transaction from report results when the transaction has it. If a tag is both included and excluded, the exclusion applies.
_Avoid_: Omitted tag

**Savings**:
Money set aside for future use.
